## 🎵 Описание проекта

**Crazy Music** - это инновационное мобильное приложение для создания музыкальных композиций с использованием звуков овощей. Пользователи могут создавать, сохранять и делиться своими уникальными мелодиями.

### 🎯 Цель проекта
Создать креативное и увлекательное приложение, которое:
- Позволяет создавать музыку из нестандартных звуков
- Предоставляет интуитивно понятный интерфейс для композиции
- Сохраняет историю созданных мелодий
- Дает возможность делиться творениями с друзьями

### 👥 Целевая аудитория
- **Творческие личности** - люди, интересующиеся экспериментальной музыкой
- **Дети и подростки** - для развлечения и развития музыкального слуха
- **Преподаватели музыки** - как образовательный инструмент

## ✨ Возможности приложения

### 🎹 Создание музыки
- **Интерактивный интерфейс** - перетаскивание овощей на горшки для создания звуков
- **Тайминг и последовательность** - установка времени воспроизведения каждого звука
- **Различные овощные звуки** - апельсин, вишня, яблоко, клубника, тыква, виноград
- **Редактирование композиций** - изменение порядка и времени звучания

### 💾 Управление композициями
- **Сохранение мелодий** - автоматическое сохранение созданных композиций
- **Просмотр истории** - список всех созданных мелодий с деталями
- **Воспроизведение** - прослушивание сохраненных композиций
- **Удаление** - управление списком сохраненных мелодий

### 📤 Шаринг и экспорт
- **Поделиться музыкой** - отправка аудиофайлов через мессенджеры
- **Экспорт композиций** - создание аудиофайлов для внешнего использования
- **Текстовое описание** - автоматическая генерация информации о композиции

### ⚙️ Дополнительные функции
- **Система уведомлений** - оповещения о действиях
- **Локализация** - поддержка русского языка

## 🏗️ Архитектура

### 📱 Frontend (Android)
Приложение построено на нативной Android разработке с использованием:

- **Activity-based архитектура** - каждая функциональность в отдельном Activity
- **RecyclerView** - для списков композиций
- **MediaPlayer** - для воспроизведения звуков
- **FileProvider** - для безопасного обмена файлами

### 🎵 Звуковая система
- **Raw ресурсы** - звуки овощей хранятся как raw ресурсы
- **MediaPlayer управление** - одновременное воспроизведение нескольких звуков
- **Тайминг система** - точное управление временем воспроизведения

### 💾 Система хранения данных
- **SharedPreferences** - для настроек приложения
- **Внутреннее хранилище** - для сохранения композиций
- **Внешнее хранилище** - для временных файлов шаринга
